# Security Policy

## Supported Versions

The following table describes which versions of VocalAssistAI currently receive security updates.

| Version | Supported |
| ------- | --------- |
| Latest (main branch) | ✅ Yes |
| Pre-release builds | ⚠️ Best effort |
| Older commits | ❌ No |

If you discover a security issue, please upgrade to the latest version before reporting it.

## Reporting a Vulnerability

If you discover a security vulnerability in VocalAssistAI, please do **not** create a public GitHub issue.

Instead:

1. Email the maintainer or use GitHub Security Advisories (if enabled).
2. Include:
   - Description of the vulnerability
   - Steps to reproduce
   - Impact assessment
   - Suggested mitigation (if known)
3. You should receive an acknowledgement within **3-5 business days**.
4. Critical vulnerabilities will be prioritized and patched as soon as possible.

Thank you for helping keep VocalAssistAI secure.
